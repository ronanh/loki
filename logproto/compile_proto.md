# logproto and stats Go code

`logproto.pb.go` and `../logql/stats/stats.pb.go` were generated by `protoc-gen-gogoslick` from the `.proto`
files next to them. The calls into the gogo runtime were then removed by hand, so these packages do not depend
on `github.com/gogo/protobuf`. The files can no longer be regenerated as they are.

Treat both files as frozen. Servers and clients of different versions exchange these messages over gRPC during
a rollout, so the wire format must not change. `wire_test.go` holds golden bytes that fail on any change.

gRPC encodes these types through the legacy message support of `google.golang.org/protobuf`. It needs only the
`Descriptor()`, `Marshal()` and `Unmarshal()` methods. Time fields are encoded as `google.protobuf.Timestamp` by
`timestamp.go`. The `.proto` files remain the reference for the schema.
